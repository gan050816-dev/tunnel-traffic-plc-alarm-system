# PLC 隧道车流控制与远程报警系统

## 项目简介

本项目整理了隧道左右车道控制、WinCC 监控画面和远程报警配置，体现 PLC、HMI 与远程通信模块的联合应用。

## 主要内容

- TIA Portal PLC/HMI 工程。
- WinCC 隧道左右车道监控画面与运行项目。
- 远程模块变量映射、左右车道异常报警和设备通信配置。

## 目录结构

```text
TIA_Portal工程/      原始 PLC/HMI 工程目录
WinCC工程/           WinCC 组态工程与画面
远程报警配置/        已脱敏的 GRM 工程配置
```

## 环境依赖

- Siemens TIA Portal V15.1 或兼容版本。
- Siemens WinCC Classic 对应版本。
- GRM 远程模块工程工具，仅在继续编辑远程报警配置时需要。

## 使用方法

1. 使用 TIA Portal 打开 `TIA_Portal工程/plc作业.ap15_1`。
2. 在 WinCC 中打开 `WinCC工程`，检查变量连接与画面引用。
3. 连接真实设备前重新设置 PLC 地址、远程模块地址和报警接收人。
