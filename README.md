# PLC 隧道车流监控与远程报警课程设计

围绕隧道左右车道的监控与异常提示，组织 PLC/HMI 工程、WinCC 车道画面和 GRM 远程报警配置。**PLC 中的车道变量与异常标志分别用于 WinCC 监控显示和 GRM 远程报警规则**，对应现场控制、监控显示与异常通知三部分工程内容。

**当前成果是 TIA Portal 工程、WinCC 画面文件和两条车道异常报警配置，尚无完整联机验证。** 通过现有文件，可以追踪“读取哪些变量、由什么条件触发报警”。

## 从异常信号到报警的关系

远程配置中，左右侧错误标志分别映射到 `变量3` 和 `变量4`：

| 方向 | 触发条件 | 当前配置可确认的含义 |
| --- | --- | --- |
| 右车道 | `变量4 == 1` | 触发右侧报警；报警描述为“右车道数量小于0” |
| 左车道 | `变量3 == 1` | 触发左侧报警；该规则没有填写更具体的异常描述 |

阅读时可以沿“PLC 异常标志 → 远程变量 → 报警条件”追踪配置，再进入 TIA Portal 的相应程序网络查看异常标志的生成逻辑。

WinCC 画面呈现车道状态；GRM 的 S7-1200 TCP 连接配置直接指向 PLC，并按异常标志设置远程报警规则。

## 关键设计

- **左右车道分别映射。** 两个方向使用独立的数值变量和异常标志，便于分别查看和配置报警。
- **显示与报警分开组织。** WinCC 保存监控画面，远程模块保存变量和触发规则，阅读时可以分别追踪显示对象和报警条件。
- **用异常标志连接程序与报警。** PLC 程序生成的错误标志映射为远程变量，远程模块按布尔条件触发相应规则。

## 公开文件与打开方式

```text
TIA_Portal工程/
  plc作业.ap15_1          TIA Portal 工程入口及关联文件
WinCC工程/
  suidao.MCP              WinCC 工程入口
  GraCS/                 主画面与左右车道画面
远程报警配置/
  工程.GRMPRJ             变量映射、连接和报警规则
```

需要 Siemens TIA Portal V15.1 或兼容版本、与工程匹配的 WinCC Classic，以及用于查看或编辑远程配置的 GRM 工程工具。

建议按以下顺序阅读：

1. 用 TIA Portal 打开 `TIA_Portal工程/plc作业.ap15_1`，查看硬件组态、变量与控制程序。
2. 用 WinCC 打开 `WinCC工程/suidao.MCP`，检查主画面、左右车道画面及变量连接。
3. 用 GRM 工程工具查看 `远程报警配置/工程.GRMPRJ`，核对四个业务变量和两条报警规则。
4. 如需联机演示，先在自己的实验环境中重新核对型号、I/O 映射、通信连接及报警接收设置，再验证正常计数、异常触发与恢复过程。

## 当前边界与公开范围

- 待补验证包括工程编译、下载、正常计数、异常触发、复位与实际报警送达；尚无计数精度、响应时间和稳定性的测量结果。
- 当前未提供可直接浏览的 WinCC 运行截图、关键梯形图导出或报警接收截图。
- 报警接收号码已脱敏；连接参数、控制逻辑、联锁及急停需要在具体实验设备上重新核对，课程工程不能直接用于生产现场。
- 公开文件不包含厂家安装程序、证书、驱动运行库、备份压缩包和部署包。
